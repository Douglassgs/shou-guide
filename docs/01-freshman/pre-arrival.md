# 行前准备与行李清单

出发前往临港校区（上海市浦东新区沪城环路999号）之前，建议仔细对照以下清单准备行李。


## 必带证件与材料清单

| 类别 | 项目 | 说明 |
| :--- | :--- | :--- |
| **录取与身份** | 录取通知书原件 | 报到核验必备 |
| | 居民身份证原件及复印件若干 | 办理银行卡、入学资格复查等备用 |
| | 户口迁移证明（若需迁户口） | 根据个人意愿，按录取须知要求办理 |
| **档案与党团关系** | 高中纸质档案袋 | **切勿私自拆封**，自带或通过机要寄送 |
| | 团员证、入团志愿书 / 党组织关系介绍信 | 团员档案须完整 |
| **照片与财务** | 近期一寸/二寸白底/蓝底免冠证件照 | 建议各准备 8-10 张，同时存好电子版 |
| | 随通知书寄发的银行卡 | 预存学杂费、住宿费，激活后用于发放奖助学金 |
| | 贫困证明 / 家庭经济困难认定材料 | 如需申请助学贷款或绿色通道 |


## 个人生活用品

- **床上用品**：
  - 床铺尺寸通常为 **0.9m × 2.0m**（单人床）。
  - 可自带，也可在迎新现场或官方易班/后勤平台提前预订床上用品套装。
- **换季衣物**：
  - 临港靠海，风力较大，秋季昼夜温差较明显，冬季海风湿冷。建议带足防风保暖衣物（冲锋衣/羽绒服）。
  - 雨伞、雨衣或防水鞋套（临港多雨且风大，普通折叠伞容易被吹翻，推荐结实的长柄伞）。
- **洗漱与常备药**：
  - 洗漱用具、拖鞋、毛巾、衣架。
  - 感冒药、肠胃药、退烧药、创可贴、抗过敏药及防蚊驱蚊用品。


## 学习与数码装备

1. **笔记本电脑**：
   - 工科/信息类专业：建议优先配置性能较好的轻薄本或游戏本（CPU/显卡/内存需满足编程或建模需求）。
   - 文科/经管/法学类：便携长续航轻薄本即可。
2. **移动电源与插线板**：
   - 宿舍床位附近配有插座，建议携带符合新国标、带开关的安全插线板（线长建议 2-3 米）。
3. **U盘 / 移动硬盘**：
   - 课件备份与打印文印常用。
