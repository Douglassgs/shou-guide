# 校园安全与防诈骗提醒

刚踏入大学校园的新同学是电信网络诈骗分子的主要目标之一。请务必提高警惕，牢记 **“天上不会掉馅饼，转账汇款多求证”**。


## 新生高发诈骗套路

> [!WARNING]
> 任何自称“老师/辅导员/教务处/班助/公检法”并要求你通过银行卡、微信、支付宝转账或提供验证码的，**100% 是诈骗**！

### 1. 冒充学校老师/班助收费
- **套路**：不法分子通过潜入新生 QQ 群、微信群，换成与辅导员或班干部相同的头像与昵称，以“购买教材资料”、“缴纳班费/资格审查费”等名义发布收款二维码。
- **防范**：凡涉及收缴费用，**必须当面或通过官方企业微信/电话直接与辅导员确认**。

### 2. 刷单兼职与“点赞返利”
- **套路**：声称“动动手指日入数百”，先以小额佣金返利骗取信任，随后诱导下载非法 App 并进行大额垫付充值，最终以“数据卡单、流水不足”等借口拒不退款。
- **防范**：所有网络刷单均属于违法且极具欺骗性行为，坚决拒绝参与。

### 3. 助学金/退费诈骗
- **套路**：自称教育局或校财务处工作人员，谎称有“国家助学金发放”或“学费多收退费”，要求提供银行卡账号、密码及短信验证码，或要求先向指定账户转账激活。
- **防范**：学校奖助学金与退费均直接通过银行打款至随通知书发放的官方银行卡，绝不会要求学生进行任何反向转账操作。

### 4. 宿舍上门推销
- **套路**：冒充学长学姐敲门推销电话卡、文具、英语报纸、考级辅导网课或寝室宽带，多数为劣质产品或虚假会员。
- **防范**：拒绝购买任何上门推销产品，遇到可疑人员可直接向楼栋宿管或校保卫处反映。
