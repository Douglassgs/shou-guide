# 关于项目

## 为什么发起《SHOU生存指北》？

进入大学意味着迈入了一个相对自由但信息更加分散的新环境。在沪城环路999号，许多关于选课、转专业、评奖评优、保研考研、日常生活与办事的宝贵经验往往散落在各届学长学姐的零散记忆、QQ 空间、贴吧或微信群聊中。

随着时间的推移，信息极易失真或沉没，导致一届又一届的新同学重复踩坑。

《SHOU生存指北》受启发于 **南科手册（[sustech.online](https://sustech.online)）**、清华大学生存指南、北大飞跃手册等优秀开源校园社区项目，旨在打造一个属于海大人自己的**公开透明**，**实用中立**，**客观求实**，**开源共创**的百科全书。
