# 贡献指南

《SHOU生存指北》是一个**完全开源**的社区项目。无论你是已经在校的同学，还是毕业的学长学姐，都欢迎参与到指南的建设中来！


## 如何参与贡献

### 方式一：直接提交 Pull Request (推荐)

1. Fork 本项目。
2. 完成修改。
3. 提交修改并发起 **Pull Request (PR)**。
4. 审核通过后，修改将自动部署生效。

### 方式二：提交 Issue 提出建议或反馈错误

如果你发现了以下情况：
- 某项政策、电话或链接已失效。
- 某些内容存在事实错误或有待补充。
- 对网站的结构或排版有优化建议。

欢迎直接在 GitHub 仓库中提交 **Issue**。


请规范整理 Word 或 Markdown 文件提交。
